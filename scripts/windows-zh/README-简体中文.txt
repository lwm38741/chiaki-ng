chiaki-ng 1.10.1 简体中文便携版（非官方汉化）

适用平台：Windows x64（Intel / AMD）。解压整个文件夹，再运行 chiaki.exe。
默认显示简体中文。运行 Start-English.cmd 可使用英文界面。
命令行也可指定：chiaki.exe --language en 或 chiaki.exe --language zh_CN。

本版沿用上游的设置存储位置；“便携版”指免安装程序包，设置并不隔离在解压目录。
升级前请在“设置 > 配置”中导出配置。勿只复制 chiaki.exe，旁边的 DLL、qml、plugins 和 translations 目录均需保留。
PSN 登录网页由 Sony 或外部账户查询服务提供，网页语言不属于本客户端汉化范围。
技术诊断日志及底层库错误原文可能保留英文，以便排障；主要界面、设置、配对及应用提示已翻译。
